# 大事件 - 前端项目
基于 Vue3 + Vite + Element Plus 开发的个人文章管理系统前端。

## 配套后端
后端仓库：https://github.com/nailong666/big-event
后端使用 SpringBoot + MyBatis + Redis + MySQL + OSS

## 说明
本项目为学习练习项目，前后端分离架构。

## 技术栈
- Vue3 + Composition API
- Vite
- Element Plus
- Pinia（状态管理）
- Vue Router
- Axios

## 项目功能
1. 用户登录、注册、重置密码
2. 个人信息修改、头像上传
3. 文章分类管理
4. 文章发布、编辑、删除、列表查询

## 项目启动
```bash
# 安装依赖
npm install

# 本地运行
npm run dev

# 打包构建
npm run build
